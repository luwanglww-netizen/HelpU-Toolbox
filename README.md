# HelpU 工具箱

HelpU 是一款面向 Windows 和 Android 的实用工具箱，目前提供：

- 下载视频与图文作品
- 提取视频文案
- 超强情感配音

## 下载

请前往 [Releases](../../releases/latest) 下载最新版本。

- Windows：下载 `Windows-x64` ZIP，完整解压后运行 `helpu_toolbox.exe`。
- Android：下载 `Android-arm64-v8a` APK，支持 Android 8.0 及以上的 64 位 ARM 手机。

Windows 版本为便携压缩包，当前未购买商业代码签名证书，首次运行时 Windows 可能显示安全提醒。

本仓库仅提供 HelpU 软件成品，不开放源代码。
